# Import des logements Airbnb

L’adaptateur `airbnb-public/1.0` lit les pages publiques `/rooms/{id}` sur les domaines Airbnb français et international. Il vérifie la référence (y compris l’identifiant encodé de `VacationRental`), le canonique et les données de partage, puis lit le titre, la ville et la description du logement. La galerie de la visite photo fournit les images dans l’ordre publié ; le JSON-LD sert de repli. Les recommandations, portraits des hôtes, avis et calendriers ne sont pas importés. Aucune API privée, session Airbnb ou exécution JavaScript n’est nécessaire.

Les photos proviennent uniquement de `a0.muscache.com/im/pictures/`, avec contrôle de la référence `Hosting-{id}` lorsqu’elle est présente. La variante `im_w=1440` limite les originaux téléchargés ; le transport habituel contrôle DNS/IP, redirections, taille, décodage et normalisation JPEG. Les plafonds de galerie et de téléchargement existants s’appliquent.

Le logement est importé comme une **location**. Les prix Airbnb dépendent des dates et des voyageurs : aucun prix par nuit, séjour ou promotion n’est enregistré comme un loyer mensuel. La surface reste absente si elle n’est pas explicitement publiée en mètres carrés. Le nombre de chambres, de lits et la capacité d’accueil ne sont jamais pris pour un nombre de pièces.

Recette du 19 octobre 2026 : le lien fourni (`1574033703710946850`) donne un appartement à Paris, une description complète et **9 photos distinctes normalisées**, sans rejet et sans navigateur, via le transport HTTPS sécurisé local. Les preuves réelles et médias restent ignorés par Git dans `evidence/local/airbnb-import/`. Les tests synthétiques couvrent la cohérence des identités, les URL dangereuses, la séparation des recommandations, les variantes de domaine, le repli sans hydratation et l’import complet. Un refus d’accès ou une page retirée conserve les erreurs habituelles ; cette recette ne promet pas la compatibilité de toutes les annonces Airbnb.
